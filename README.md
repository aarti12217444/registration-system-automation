# 🚀 Registration System Automation Project

An intelligent Registration System built with **HTML, CSS, JavaScript** and automated using **Java + Selenium WebDriver**.  
This project demonstrates the complete flow of **manual form interaction** and **automated validation testing**.

---

## ✨ Key Highlights

✅ Responsive registration form  
✅ Client-side validations  
✅ Selenium automation (Negative + Positive test cases)  
✅ Chrome automation using ChromeDriver  
✅ Maven-based Java project  
✅ Clean project structure  
✅ GitHub version control

## ⚙️ Automation Flow

1️⃣ Chrome browser launches  
2️⃣ Registration form opens  
3️⃣ Negative test case runs (missing fields)  
4️⃣ Page refresh  
5️⃣ Positive test case runs (valid inputs)  
6️⃣ Form submitted successfully  
7️⃣ Browser closes automatically  

---

## 🧪 Test Scenarios

### 🔴 Negative Test
- Leave mandatory fields empty  
- Verify form does not submit  

### 🟢 Positive Test
- Enter valid user details  
- Accept terms  
- Submit form successfully
